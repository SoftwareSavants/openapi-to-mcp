## Quick Start

```bash
npm install
cp .env.example .env   # fill in your API key
npm run build
npm start
```

```json
{
  "mcpServers": {
    "notion-api": {
      "command": "node",
      "args": [
        "--env-file=path/to/notion-api-mcp/.env",
        "path/to/notion-api-mcp/dist/index.js"
      ]
    }
  }
}
```
